# Lịch xe Hixe

Công cụ theo dõi lịch xe cho thuê: tích ngày xe đi / ở nhà, ghi giá thuê, người thuê, số điện thoại, chi phí, xem dashboard doanh thu – chi phí – lãi và xuất PDF theo xe, theo tháng.

## Chạy

Mở `index.html` bằng trình duyệt, hoặc bật GitHub Pages cho kho này (Settings → Pages → Branch `main`).

## Lưu ý

- Khi chạy ngoài Claude, dữ liệu được lưu trong trình duyệt (localStorage) của từng máy, không đồng bộ giữa các thiết bị.
- Tải ảnh CCCD chỉ hoạt động trong bản chạy trên Claude.
- Kho này chỉ chứa mã nguồn, không chứa dữ liệu khách thuê.
